# belt_editor — сборка ленты перетаскиванием

Экран ручной сборки пути корпуса. Две области: слева **элементы**, справа
**лента** — элементы перетаскиваются на неё, из них собирается конвейер.
Ничего больше на экране нет: без оборудования, без Node.js, один
HTML/JS/CSS и статический сервер из стандартной библиотеки.

## Запуск

```bat
run_belt_editor.bat
```

откроет `http://127.0.0.1:8020/` (или вручную:
`python -m http.server 8020` из этой папки; страница работает и открытием
`index.html` с диска).

## Элементы (перетаскивать на ленту)

| Элемент | Действие |
|---|---|
| **Позиция** | слот ленты; бросок между карточками вставляет по месту, полоска-маркер показывает, куда встанет |
| **Место инспекции** | бросок НА позицию делает её инспекционной; повторный бросок снимает инспекцию |
| **Камера** | бросок на позицию добавляет камеру в её место инспекции (на неинспекционную — позиция становится инспекционной); клик по фишке камеры убирает её, двойной клик — переименовать роль |
| **Точка сброса** | бросок на позицию: корпус покидает ленту здесь; точка одна — переносится на новое место, повторный бросок на занятую снимает |

## Правила, которые держит модель

1. Если место инспекции на ленте **одно**, оно автоматически становится
   **основным** — определяет наличие детали (part_presence).
2. Если мест инспекции два и больше, основное выбирается кликом по значку
   «инспекция» на карточке (по умолчанию — самое раннее).
3. Точка сброса на ленте ровно одна.
4. Корпус едет по порядку П0 → П1 → … → точка сброса, дальше — выход.
5. Лента: максимум 64 позиции.

## Вспомогательные жесты

- карточку позиции можно таскать по ленте — менять порядок;
- ✕ на карточке — удалить позицию;
- двойной клик по названию — переименовать;
- статусная строка под лентой всегда показывает, хватает ли элементов
  для валидной линии.

## Формат

Внутреннее состояние позиции — `{label, inspection: {cameras, primary},
reset}` — повторяет контракт `belt.path.v1` будущей универсальной системы,
так что собранная лента сохранится позже без переработки модели.
