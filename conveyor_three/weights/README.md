# Веса моделей трёхкамерной линии

Файлы весов (`.pt`) **не входят в репозиторий**. Скопируйте их сюда из папки
`new_weights` эталонного трёхкамерника (`transporter/new_weights/`), сохранив
имена — `vision/model_config.py` обращается к ним по этим путям:

| Файл                    | Камеры        | `kind`           | conf | Назначение                     |
| ----------------------- | ------------- | ---------------- | ---- | ------------------------------ |
| `windows_4.pt`          | NEAR, FAR     | `uneven_heights` | 0.70 | ячейки окон (разновысотность)  |
| `shells.pt`             | NEAR, FAR     | `window_sinks`   | 0.80 | раковины в окнах               |
| `bottom_glass_new_v3.pt`| MIDDLE        | `bottom_glass`   | 0.65 | стекло на дне                  |
| `welding_new_2.pt`      | MIDDLE        | `welding`        | 0.65 | брак сварки                    |

Требования к моделям — как в трёхкамернике: YOLO-сегментация
(`task="segment"`), inference с `iou=0.0`, `imgsz=1280`, без подавления NMS.
Имена классов внутри весов не используются: постобработка определяется полем
`kind` из `vision/model_config.py`, а каждой детекции проставляется `kind` её
модели.
